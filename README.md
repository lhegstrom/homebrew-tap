# lhegstrom/homebrew-tap

Homebrew casks for my apps.

| App | Install |
|---|---|
| [ClaudeNotify](https://github.com/lhegstrom/ClaudeNotify) — menu bar notifier for Claude Code sessions (unofficial; not affiliated with Anthropic) | `brew install --cask lhegstrom/tap/claudenotify` |

Using the full `lhegstrom/tap/<name>` taps this repo and trusts only that cask. After the first install, `brew upgrade` and `brew uninstall` work by the short name.
